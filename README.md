# ToDo

Minimale To-Do-App für Android: heutige Aufgaben bildschirmfüllend, Eingabe per Text oder Sprache, Wochenübersicht per Pinch-Zoom, Erinnerung bei offenen Aufgaben, Übertrag um Mitternacht und Homescreen-Widget.

## Installieren

1. Auf dem Handy die [neueste APK](../../releases/download/neueste/ToDo.apk) herunterladen.
2. Öffnen und installieren. Beim ersten Mal fragt Android, ob der Browser bzw. Dateimanager Apps installieren darf: erlauben.
3. Updates genauso: neue APK herunterladen und über die alte installieren. Die Aufgaben bleiben erhalten.

Das Widget fügst du über langes Drücken auf den Homescreen → Widgets → „ToDo heute“ hinzu.

## Bauen

Jeder Push auf `main` startet die GitHub Action: Unit-Tests, APK bauen, APK an das Release `neueste` hängen.
